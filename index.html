Hello, My name is Jeremiah, a fourth-year Computer Science student at Holy Angel University in Angeles City, Philippines. I enjoy many areas of computing, from programming and software development to machine learning, and I am especially interested in new technologies and what they can do.

My main project is TumbleTrack, a laundry tracker for students that I built from the database to the screen. It uses a PostgreSQL database, an Express API (the part that connects the website to the database) that checks incoming data and requires a login, and a React website that works well on mobile devices. Building it taught me how to keep an API secure, check data on the server, and fix problems that only appear on phones, such as a login prompt that some mobile browsers skipped. I also put it online myself, with the website on GitHub Pages and the API on Render.

Before that, I co-developed Sentral Stocks, an inventory system that helps a café keep track of its supplies. I was responsible for the backend and database. I designed the SQLite tables, connected them to the Ruby backend, fixed errors when adding, editing, and deleting items, and added user roles so admins and staff can only do what their role allows.

These projects have strengthened my problem solving, communication, adaptability, and teamwork, and especially my software development skills. I keep learning through online courses to keep up with a fast-changing industry.

I am now looking for an on-the-job training placement where I can work with a team, handle real-world tasks, and learn more how software is built and maintained in a real workplace.

Projects

  • TumbleTrack

    Individual course project, Holy Angel University · Full-stack developer (built with AI assistance, Claude)

    A laundry tracker for students. It needs no sign-up, because each person's data is separated by a per-browser device ID. It has a PostgreSQL schema on Neon, an Express REST API with six endpoints, server-side validation, a CORS allowlist and HTTP Basic Auth, plus an accessible, responsive React front end with four pages. It is deployed to GitHub Pages with GitHub Actions, and the API runs on Render.

  • Sentral Stocks

    Team project, Holy Angel University · Co-developer (backend and database)

    A web app that helps a café track supplies such as beans, dairy, syrups, cups and equipment in one place. I built the backend and database: a relational SQLite schema with more than eight inventory categories linked by foreign keys, connected to the Ruby backend through ActiveRecord.
