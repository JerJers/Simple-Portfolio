# Jeremiah Carbungco | Digital Portfolio

A personal portfolio website for Jeremiah Carbungco, a 4th year BS Computer Science student at Holy Angel University in Angeles City, Philippines. It presents my background, skills, certifications, education, achievements, and projects.

## Sections

- Home
- Skills
- Certifications
- Education
- Achievements
- Projects
- Contacts

## Features

- Fixed sidebar on the left with a section menu that highlights the section you're reading
- Scrollable content on the right
- Responsive layout that works on desktop and phones
- Dark theme by default, with a light theme for devices set to light mode
- Plain HTML, CSS, and a few lines of JavaScript, with no build step or dependencies

## Built With

- HTML
- CSS
- JavaScript
- Google Fonts (Bricolage Grotesque and DM Sans)
